## Intent

Agent **không** spam `GET /api/jobs`. Một tool = start stage (nếu cần) + **chờ terminal** (poll manifest **bên trong** tool) rồi mới bước sau.

## API tools

| Tool | Hành vi |
|------|---------|
| `pineline_run_stage` | Fire-and-forget (cũ) |
| `pineline_run_stage_wait` | Skip nếu done & !force; else start/join → wait done\|failed\|stop\|timeout |
| `pineline_pipeline_loop` | Chuỗi stage tuần tự, mỗi bước wait |

## SAFE autofix sau swarm

- Phân biệt Stop (`.stop` / cur_text) vs salvage `pending`
- `force` qua `_truthy` (tránh `"false"` → True)
- 409 busy → join wait
- Manifest `status=error` terminal; pending quá lâu không running → fail sớm

## Còn mở

- Cascade TTS khi `run_stage(translate)` status≠done (server)
- SYSTEM prompt agent chưa ưu tiên `*_wait`
- Cần **restart :8801** để Telegram/agent in-process nạp tool mới
