- **Date:** 2026-11-09
- **Job / khu vực:** `meta_studio.generate_ai_image` / `/api/meta/ai-image` (Films UI)
- **Status:** fixed
- **Backup zip:** `Z:\PinelineV2_backup_2026-11-09_1358.zip`

## Triệu chứng

Nút tạo ảnh Meta / thumbnail AI trên Films UI fail hoặc treo; trong khi chat GPT local `:3377` vẫn sống.

## Root cause

Không phải account ChatGPT/Aurora “hỏng”. `meta_studio._call_chatgpt` / `generate_ai_image` chỉ đọc `os.getenv("CHATGPT_BASE_URL")` / `AURORA_BASE_URL`, **bỏ qua** `pineline.config.json` (đã set `http://127.0.0.1:3377/v1` + `sk-local`). Process sidecar/server thường không export env đó → lần lượt thử Aurora `:5005` (chậm/timeout/fail).

## Evidence

- Config có `CHATGPT_BASE_URL=…3377/v1`, `CHATGPT_API_KEY=sk-local`.
- Trước fix: candidate URL trong meta chỉ env + Aurora LAN.
- Sau fix CLI: `bases ['http://127.0.0.1:3377/v1', …5005…]`, `generate_ai_image(…)` → **1571476 bytes / ~23.4s**.
- `:3377/v1/models` trả `gpt-5-6` / mini — local proxy OK.

## Fix

- `meta_studio.py`: `_cfg` / `_chatgpt_candidate_bases` / `_get_chatgpt_token` — đọc config rồi env; ưu tiên :3377; Bearer `sk-local`.
- `generate_ai_image` + `_call_chatgpt` dùng helpers đó; timeout ảnh theo `CHATGPT_TIMEOUT` (floor ~180).
- `agent_tele_cmd.py`: `/api/meta/ai-image` timeout 150→300; message lỗi rõ local/Aurora.
- Sync V2/V4/V5. Sidecar **reload** `meta_studio` mỗi request → ảnh đã hiệu lực không cần restart :8802; timeout handler trong `agent_tele_cmd` cần restart :8802 nếu muốn nạp 300s.
